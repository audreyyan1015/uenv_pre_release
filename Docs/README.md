# UEnv 文档入口

面向安装、使用和接入的正式手册从 [`UEnv 使用手册`](./guide/1-了解UEnv/01-index.md) 开始。首次阅读请按手册中的连续主路径完成：单机部署、多机部署、评测、强化学习训练和轨迹采集。

`Docs/guide/` 之外的目录主要保存历史设计、开发记录、联调报告和内部规格，可能包含旧组件名、旧端口或已经变化的命令。它们不能替代正式手册、当前发布配置或协议定义。

| 需求 | 权威入口 |
|---|---|
| 安装与使用 | [`Docs/guide/`](./guide/1-了解UEnv/01-index.md) |
| 当前配置模板 | [`deploy/config/`](../deploy/config/) |
| 当前协议 | [`proto/`](../proto/)、[`uenv-worker/proto/`](../uenv-worker/proto/)、[`plugin_proto/`](../plugin_proto/) |
| 构建与测试 | [仓库 README](../README.md) |
