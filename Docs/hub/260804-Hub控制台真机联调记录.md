## 1. 部署与隔离

真机上 8088 已有一个生产 Hub 在跑，且 `/root/uenv` 工作区有未提交改动，
因此**没有**在原目录上操作，而是另开一份：

```bash
# 本地：提交并推分支
git push origin feature/worker-pool-260728_HubEpisodeStackRubric   # -> 0e46fd4

# 真机上无 git 凭据，改用 rsync 同步（排除 .git/ target/ data/）
rsync -az --delete --exclude '.git/' --exclude 'target/' --exclude 'data/' \
  ./ root@8.130.95.176:/root/uenv-console-e2e/
```

e2e 实例独立于生产实例的一切状态：

| 项 | 生产实例 | e2e 实例 |
|----|----------|----------|
| 目录 | `/root/uenv` | `/root/uenv-console-e2e` |
| 端口 | 8088 | 18091 |
| 数据库 | `.../uenv-hub/data/hub.db` | `.../.e2e/hub.db` |
| 产物目录 | 生产产物库 | `.../.e2e/artifacts` |
| 鉴权 | 强制 Token | 开放（仅本机监听 + 隧道访问） |
